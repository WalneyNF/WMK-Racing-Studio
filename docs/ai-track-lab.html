Academy 07 — Laboratório IA e WRTL

Abrir laboratório

Executar no Windows

Na raiz do projeto execute:

python ai/server.py

Abra http://127.0.0.1:8768/ai/. Sem dependências Python externas. Ollama deve estar executando na porta 11434 e ter o modelo instalado. Para Groq, configure GROQ_API_KEY no ambiente do terminal antes de iniciar; nunca publique a chave. O servidor só escuta localhost.

Fluxo

Prompt + knowledge.txt + schema → provedor → JSON → validação WRTL → postMessage de mesma origem → motor Extreme no iframe. Nenhum código produzido pela IA é executado. O exemplo funciona sem provedor, inclusive em servidor estático. A prévia usa a mesma implementação do jogo.

WRTL 0.1

{
  "name": "Neon AI Loop",
  "type": "double",
  "radius": 35,
  "scale": 1,
  "width": 16,
  "bank": 0,
  "accent": 65535
}

Tipos existentes e custom XYZ. Não suporta ainda biblioteca modular arbitrária. O validador verifica campos, limites e pontos consecutivos, não auto-interseções. O pedido pode exigir aproximações. Consulte schema e instruções.

Testes e limites

Teste primeiro exemplo, depois Ollama e Groq. Compare tempos, validade e qualidade. Conexões reais e renderização precisam ser verificadas no computador do usuário. Futuro: histórico, biblioteca de peças, reparo iterativo, agente validador geométrico e testes com bots.
