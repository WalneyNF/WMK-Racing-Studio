Abrir laboratório

Painéis

Arraste pela barra de título, redimensione pelo canto inferior direito, feche no X e reabra em Painéis. O layout fica no localStorage do navegador. Viewport limpa oculta temporariamente todos os painéis.

Testes

Prepare um dos três experimentos e gere com IA. Compare campos esperados, tempo de resposta, JSON original e normalizado. Clique na viewport para dirigir. Os botões de teste enviam comandos restritos ao iframe de mesma origem.

Ensinar Qwen

Selecione preset para restringir o schema a sete campos, sem pontos nem torções. Custom exige pontos. Temperatura Ollama 0,1. Salve instruções adicionais e aprove até cinco exemplos de JSON validados; são inseridos no contexto da próxima requisição, não retreinamento. Não envie segredos. Validação estrutural não prova jogabilidade. Reinicie python ai/server.py após atualizar. Groq recebe schema como instrução e modo JSON, não garantia de conformidade.
