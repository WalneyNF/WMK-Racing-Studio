Track Forge 0.1 — laboratório de receitas

Compatível com WRTL 0.1. A receita não é uma pista importável diretamente: forge.js compila para custom XYZ. O contrato da WRTL permanece inalterado.

Como usar

  1. Execute python ai/server.py e abra http://127.0.0.1:8768/ai/.
  2. Abra Track Forge na barra superior.
  3. Clique Forjar pista para usar o exemplo, ou Nova variação para mudar a semente.
  4. Edite a receita, compile e teste em Pilotar. Exporte o JSON WRTL no painel Projeto; Salvar receita guarda a origem procedural.
  5. Para IA, selecione provedor/modelo no Projetista e escreva um pedido. Clique Projetar receita com IA na Forja.
  6. Após testar, aprove a receita para incluir até cinco exemplos no contexto de próximas receitas.

Receita

{
  "name": "Neon Dragon Forge",
  "shape": "dragon",
  "seed": 7000,
  "size": 220,
  "height": 70,
  "waves": 4,
  "twists": 2,
  "width": 14,
  "bank": 35,
  "color": "purple"
}

O catálogo inclui ring, flower, star, dragon e figure8. Cada receita gera 120 pontos por funções trigonométricas e um gerador pseudoaleatório determinístico. A mesma receita produz os mesmos pontos. size controla a escala horizontal; height e waves controlam ondulações (figure8 tem fórmula própria); twists gira a normal; color usa nomes para evitar erros RGB. Consulte schema.

Exercícios

Compare seeds 7000 e 7001; altere shape para flower; gere dragon com três torções; peça ao Qwen uma receita com cor orange e compare com Groq. Teste visualmente antes de aprovar. As receitas não são treinamento de pesos.

Limitações

Não é ainda WRTL modular; não gera loopings verticais explícitos, túneis, saltos ou encaixes de peças. A validação estrutural não assegura ausência de auto-interseções ou conforto de pilotagem. Testes gráficos e chamadas reais de IA pendentes. A separação vertical de figure8 é nominal, não uma garantia de colisão.
